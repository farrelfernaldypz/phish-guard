    SYSTEM DESIGN & PRINCIPLES

    Defensive Analytical Pipeline

    01

    Deterministic Normalization

    RFC 3986 lexical sanitation. Isolates authority, scheme, path hierarchy, and query parameters. Internationalized domain labels are decoded to canonical ASCII IDNA without initiating host lookup calls.

    02

    Feature Vector Alignment

    Computes 11 mathematical metrics across structural lengths, delimiter frequencies (@, -, ., /), suspicious credential keywords, raw numeric IPv4 address usage, and transport security protocols.

    03

    Ensemble Forest Inference

    Evaluated by a 100-tree Scikit-Learn Random Forest ensemble. The positive class probability is benchmarked against a calibrated 0.50 decision boundary to produce an immutable verdict with sub-25ms response latency.
